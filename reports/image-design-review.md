# 图像分支独立设计评估

日期：2026-09-22。范围：当前 `image_experiment.py` 的数学对象、表达能力和证据解释。本评估不预判真实图像训练结果，也不将单元测试通过视为复杂图像生成成功。

**结论：这是可以执行、也容易被反例检验的高维概率流压力实验；它检验的是已知平滑经验分布的自洽输运。当前固定低秩表示有明确的分布表达限制。即使运行成功，也须另行评价是否生成可辨认、足够多样、超出训练中心复现的图像。**

## 1. 与原论文的理论对象不同

原文第 2 节采用周期盒域；第 3.2 节的目标包含自洽残差的零、一、二阶空间导数；第 4 节定理还要求统一的高阶正则性。论文实验为二维高斯初值及二次势。[原文，PDF 第 3、6、9、13 页](https://proceedings.mlr.press/v178/shen22a/shen22a.pdf)

当前图像分支在整个 \(\mathbb R^{3072}\) 上求解
\[
\partial_t\alpha=\nabla\cdot(x\alpha)+\Delta\alpha,
\qquad r=v+x+s,\qquad
L=\frac1{3072}\int_0^T\mathbb E_{\rho_v(t)}\|r\|^2dt.
\]
图像坐标归一化到 \([-1,1]\) 不表示施加像素边界：加噪和流均可越界。训练的 score 来自初始密度并沿同一速度场传播，没有自由 score 网络，也没有使用真实 OU 中间时刻的 score 监督。[实际实现](</Users/yuchen/3. Project/Low priority/随机分析证明/fpe_solver/src/fpe_solver/image_experiment.py:126>)

因此，不能直接套用原文周期 Sobolev 目标的保证。即使另外建立零阶残差的条件熵估计，相关量也是 \(R_0=3072L\)，不是每像素平均损失；总体积分、有限样本估计和数值离散仍应分开。本分支没有高维误差证书，也没有验证算法自进化收敛。

## 2. 已知 GMM 提供了什么、没有提供什么

本实验固定 512 个训练图中心 \(c_i\)，初值为
\[
p_0(x)=\frac1{512}\sum_i\mathcal N(x;c_i,0.2^2I).
\]
其采样与初始 score 都可精确计算；真实 OU 终态也是已知 GMM，可供独立诊断。这里的“精确”指公式，不免除浮点误差。256 张官方测试图仅用于事后对照，不进入这个初值分布。[GMM 实现](</Users/yuchen/3. Project/Low priority/随机分析证明/fpe_solver/src/fpe_solver/image_experiment.py:40>) CIFAR-10 本身是 32×32 彩色图像数据集；本实验不是高分辨率图像评测。[数据集原始页面](https://www.cs.toronto.edu/~kriz/cifar.html)

这消除了“只有数据、未知密度与 score”的学习难点。因此结果不能外推为从任意自然图像样本学习其未知分布。目标本来就能通过“随机选择中心并加噪”直接采样；逆流模型在这个实验中没有天然的采样效率优势。重现训练中心附近的加噪图，可能符合已声明的 GMM 目标，却不足以支持新颖图像生成的主张。测试图最近邻只能提供外部参照，不能改变模型实际学习的分布。

## 3. rank 32、三次时间基的结构约束

实际速度的非线性修正为
\[
u(t,x)=B(t)\tanh(Ax+b(t))+c(t),\quad
B(t)=\sum_{j=0}^3\beta_j(t)B_j,
\]
其中 \(B_j\in\mathbb R^{3072\times32}\)，\(c(t)=\sum_{j=0}^3\beta_j(t)c_j\)。以下是对当前代码的独立结构推导，不是论文结论。[参数及场定义](</Users/yuchen/3. Project/Low priority/随机分析证明/fpe_solver/src/fpe_solver/image_experiment.py:77>)

固定一组训练完成的参数，令
\[
S=\operatorname{span}\{\operatorname{col}(B_0),\ldots,\operatorname{col}(B_3),c_0,\ldots,c_3\}.
\]
则 \(\dim S\le128+4=132\)。解析基流坐标 \(x=m(t)+a(t)y\) 中，\(\dot y=u/a(t)\in S\)，从而
\[
P_{S^\perp}y(t)=P_{S^\perp}y(0).
\]
所以从独立标准高斯逆流生成时，\(S^\perp\) 的边缘分布只能是已知仿射高斯；增加训练次数无法在这些方向创造额外的非高斯多峰结构。若训练中心差分的实际秩大于 132，则至少有不同中心投影到 \(S^\perp\)，固定架构不能精确恢复整个目标 GMM。实际秩与剩余能量应测量，不能仅凭中心数量替代。

这个结论**不**表示图像只包含 132 个像素、样本只在 132 维子空间上、或者所有输出都是联合高斯：基向量可以覆盖全部像素，剩余方向仍有满维随机噪声，\(S\) 方向的修正还能依赖 \(S^\perp\) 输入。它限制可改变的分布结构，不能单独证明视觉上一定失败。当前实现的解析共动坐标解决已知高斯基流的数值刚性，没有解除这一表达限制。

## 4. 如何判断真实结果

| 证据 | 可以说明什么 | 不能据此宣称什么 |
|---|---|---|
| 独立新样本上的残差及 128/256 步细化 | 损失是否泛化、数值误差是否影响判断；同时查看 \(L\) 和 \(3072L\) | 训练损失下降就获得高维定理保证 |
| 全部 64 张独立高斯生成图及未裁剪数组 | 是否有可辨认结构、是否塌缩、越界饱和是否掩盖错误 | 挑选几张好图证明复杂图像生成成熟 |
| 训练/heldout 最近邻及等数量参照 | 是否贴近某些中心、输出是否只是近邻变体；减少参照集大小偏差 | 最近邻较远就等于新颖；较近就等于求解已知 GMM 失败 |
| 多样性、均值、方差、饱和率 | 辅助发现同图复现、噪声增大或像素失真 | 高像素多样性就等于语义多样性；这些指标不是 FID |
| 真实 OU 终态与标准高斯的 prior mismatch | 区分“终端先验替代”与“学得流失配”；报告 MC 标准误及分量凸性 KL 上界 | oracle 终态逆流好看就算独立噪声生成成功 |

上述指标与两类终端采样在代码中分开记录。[报告字段](</Users/yuchen/3. Project/Low priority/随机分析证明/fpe_solver/src/fpe_solver/image_experiment.py:485>) 还须注意 KL 的方向：对精确可逆流 \(F\)，生成分布 \(F^{-1}_{\#}\gamma\) 相对初值的 KL 等于 \(\mathrm{KL}(\gamma\Vert F_{\#}p_0)\)。前向残差所关联的前向 KL 不能不经论证直接替换这个逆向 KL；有限样本的负 KL 估计也不能当成“比零更好”。

第一层成功是数值实现与独立参考一致；第二层成功是在冻结资源预算内可信地逼近已声明的 GMM 输运；第三层才是预先声明图像标准下的生成质量。三者分开报告，单种子试跑不代替多种子结论。当前没有预先冻结的图像质量分数门槛，因此可以报告实测成功或失败迹象，不能临时发明一个有利阈值授予“成熟”结论。

若数值检查通过但残差停滞，应先检查 \(S^\perp\) 的中心投影能量与多峰性，再单独测试扩 rank 或增加时间表示；若细化改变图像或残差，先处理数值问题；若 oracle 与独立高斯明显分离，先研究终端先验。每次只改变一个机制，保存失败图及原始参数，不用换损失、换指标或挑样本掩盖失败。
