# 真实图片生成：工程可行性检查

**rank 32 和 rank 128 的真实运行均未生成可辨认的复杂图片。** 完整 64 张输出主要为彩色噪声和模糊色块。程序在 GPU 上成功完成训练和采样，只证明这条计算路径可运行，不能据此宣布图像生成通过。

数据为[官方 CIFAR-10](https://www.cs.toronto.edu/~kriz/cifar.html) 的 32×32 RGB 图像。二进制档案 170,052,171 字节，官方 MD5 `c32a1d4ab5d03f1284b67883e8d87530` 核验一致。固定抽取 512 个训练中心、256 个独立测试样本；像素映射到 [-1,1]，在训练中心上加入 σ=0.2 高斯噪声，形成初始 score 可精确计算的已知混合分布。

这个 3072 维欧氏空间试验独立于周期 1–2 维求解器验收。它没有使用预训练生成模型，也没有用真实 OU 中间时刻 score 监督速度网络。训练从已知初始 score 出发，联合传播密度、score 和自洽残差。

## rank 32 实测结果

| 项目 | 实测值 |
|---|---:|
| 训练更新 | 500 |
| 训练时间 | 106.47 秒 |
| 受监控作业总时间 | 133.93 秒 |
| 峰值 GPU / 进程树 RSS | 672 MiB / 约 3.19 GiB |
| 独立前向验证：每坐标积分残差 | 15.6813 |
| 同一残差乘回 3072 维 | 48,172.97 |
| 对真实 OU 混合密度的终端 KL 估计 | 3,948.59 |
| 128→256 步，配对生成像素 RMSE | 0.00001512 |
| 独立高斯先验的生成样本数 | 64 |
| 未裁剪像素超出 [-1,1] 比例 | 1.855% |
| 等量训练中心最近邻平均 RMSE | 0.3383 |
| 等量独立测试最近邻平均 RMSE | 0.3221 |

以上 KL 是有限样本和有限积分精度下的估计，不是严格证书。它来自真正初始分布的**前向**演化，不使用标准高斯终端近似，因此拟合失败不能归因于生成阶段的先验替换。步长加倍造成的变化很小，也不足以解释目前明显的视觉失败。

标准高斯终端近似的误差单独记录：真实 OU 终端混合分布到标准高斯的 KL Monte Carlo 估计为 0.1382，标准误 0.0736；利用混合凸性得到的解析上界为 0.9568。它与上面的模型 KL 方向和对象不同，不能直接相加、相减或当作总生成误差。

## 单因素容量对照

已完成预先声明的 rank 32→128 对照：保持数据、seed、初始速度、学习率、500 更新、batch=16、128/256 步、T=3 与资源上限不变。两个模型均从相同的高斯基流冷启动；这不是旧模型函数保留的自动演化，不将它混入低维演化验收。

| 更新数 | 500 | 500 |

| 完整样本视觉检查 | 噪声与模糊色块 | 噪声与模糊色块 |

增加容量后，残差约降低 33.5%，但仍未得到可辨认的自然物体。这是同更新次数、相同资源上限的容量对照，实际计算时间不同；不能把它称为同实际算力实验。

## 可复核证据

- `../runs/image-seed0/report.json`：独立残差、KL、数值细化、最近邻、先验偏差和时间。
- 同目录 `raw_samples.npz` 保存未裁剪样本，`training.json` 保存全部训练曲线。
- 最终 `parameters-00500.npz` SHA-256：`632a16e0163a242e986e8e8d20068d208f9972cc19132f1f66565999a65a6117`。
- `job/` 与 `transfer-manifest.json` 保存资源限制、终态、源码和传输校验。作业成功与图像质量结论分别报告。

本试验检验的是一个具体低秩架构在已知平滑经验分布上的可行性。失败不反驳 FPE 自洽原理，也不能据此断言其他架构或更长训练一定失败；同样，低维求解器通过不能推出复杂图片生成成功。

## 本轮结论与下一步研究边界

当前实现能在低成本下执行 3072 维残差训练与逆流采样，但尚不能承担复杂图片生成任务。仅加宽这套低秩速度场不能在本轮 500 更新预算内解决问题。后续若继续，应分别检验适合图像结构的速度表示、早期快速时间变化的参数化和优化条件；每次只改一种机制，并继续用全部输出和独立前向误差检验。这里没有验证这些后续方案一定有效。

目标初始混合分布本来即可直接采样；这个回流实验的用途是检验求解/输运能力，不能把重新采到训练中心当成学会了未知自然图像分布。
